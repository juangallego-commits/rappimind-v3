# Lo que cada país imprime dentro de su documento

Generado por `node scripts/tabla-paises.js`. No se edita a mano.

Cada valor de esta tabla sale impreso en cada T&C que se publica en ese
país. Están aquí los 19 que se midieron generando el documento de cada uno:
no es una lista escrita a mano, así que si mañana una cláusula empieza a usar
una columna nueva, aparece sola.

Los 8 países con documento guardado son los que tienen caso dorado: 
CB01, MX01, PE01, AR01, CL01, EC01, UY01, CR01.
Si alguien edita la pestaña Paises del Sheet o la semilla, `npm test` se cae y
dice qué línea cambió.

Sin caso dorado de cashback: Brasil. No usa el modelo de cashback.
