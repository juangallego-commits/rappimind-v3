Key things to know immediately:
- Primary font: PP Object Sans (Regular/Medium/Bold/Heavy) — files in assets/fonts/
- Primary color: Neon gradient #FF7A4D → #FF2526 → #FF4583 at −45° — always a gradient, never flat
- Voice: El Amigo — direct, warm, benefit-first in 7 words, tuteo always, no double punctuation
- No emoji in campaign copy, OOH, UX, or email
- CTAs: max 3 words
- Paid media: always Neon + Rappi logo + country signature
- In-app / own media: can use secondary palette (Celeste, Morado, Rosado, Lavanda, Beige)
- **Brasil operates in Portuguese (PT-BR)** — same brand voice rules apply; signature is "Pede no Rappi"
